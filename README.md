# Bright Smiles Dental Clinic — Official Production Website

A patient-centric, mobile-first dental clinic website built with React, TypeScript, Tailwind CSS, and Framer Motion. Engineered specifically for **Dr. Satyam Sharma (BDS, MDS Orthodontics)** with high clinical trust, transparent pricing, and zero template clichés.

## 🚀 Key Features
- **Editorial Clinical Design**: Warm Porcelain Alabaster, Deep Obsidian Forest, and Warm Amber Gold palette.
- **Guided Appointment Scheduling**: Live treatment selection, morning & afternoon time slots, and instant client details.
- **WhatsApp & Email Integration**: Pre-formatted appointment confirmation slip dispatched directly via WhatsApp (`wa.me`) and email receipt (`mailto:`).
- **Comprehensive Clinical Services**: Detailed breakdown of treatments, durations, and transparent fee estimates.
- **Doctor Credentials**: Profile, qualifications, and patient care philosophy for Dr. Satyam Sharma.
- **100% Responsive**: Zero-lag touch interactions, dedicated mobile actions, and verified layout across all devices.

## 🛠️ Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Routing**: React Router v6
